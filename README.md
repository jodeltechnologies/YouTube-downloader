# JODEL Video Pocket for Android

## Download the Android app

**[Download Video Pocket APK](https://github.com/jodeltechnologies/YouTube-downloader/releases/download/preview/Video-Pocket.apk)**

Tap the link above on your phone, then open the downloaded APK to install. You can also open [Releases](https://github.com/jodeltechnologies/YouTube-downloader/releases/tag/preview), expand **Assets**, and select **Video-Pocket.apk**. New builds replace that same download link.


A standalone YouTube video and audio downloader. Processing runs on your phone with bundled yt-dlp, Python, QuickJS and FFmpeg. There is no download server, hosting subscription, ChatGPT sign-in, or API key.

## Install

Android 10 or later is required. After a successful build, download **Video-Pocket.apk** from this repository's **Releases > Video Pocket Android preview** and install it. The Actions tab also retains a zipped APK artifact for 30 days. Android will ask you to allow installation from the browser or file manager you use. This is a personal debug build, not a Play Store release. GitHub sign-in may be needed to download Actions artifacts.

## Use

Paste a YouTube or Shorts link, choose MP4 video or MP3 audio, choose a video quality, and tap Download to phone. Files are saved into **Downloads/Video Pocket** and remain there independently of this app. Recent entries can open saved files. No broad storage permission is requested.

From YouTube, a browser, or another app, select **Share > Video Pocket**. Shared video links download automatically by default using the last selected format and quality. Switch this off in Link capture to review links before downloading. If another download is active, the incoming link is filled for the next download and does not interrupt the current one.

Optional clipboard detection checks copied links when Video Pocket gains focus. It fills the link field without downloading automatically. Android may display a clipboard access notice. The app does not monitor other apps in the background or silently intercept every browser download. YouTube links can also be opened with Video Pocket where Android offers an app chooser. Verified YouTube app links may continue to open YouTube, so Share is the reliable path.

Download progress is shown in the app and a foreground notification. Allow notifications to see it outside the app. Android battery restrictions or force-stop can still interrupt transfers. Pause is available in the app and notification. Resume continues saved .part files and fragment checkpoints when the source supports it. Partial downloads survive app closure and phone restarts. Cancel removes the saved parts. If the source stream changes or does not support continuation, yt-dlp may restart that stream. Keep sufficient free device storage for the temporary and final files.

## Limits

- One download at a time, files up to 500 MB, video duration up to two hours, and a 30 minute download deadline.
- Live broadcasts are excluded.
- Available quality depends on the source. YouTube may reject or restrict extraction. This app does not bypass DRM or use account cookies.
- A SHA-256-verified yt-dlp 2026.10.26 release is bundled instead of the library's old 2025 engine. The app checks for official stable engine updates before the first download and then daily. Update download engine forces an immediate check. A failed update check can fall back to the recent bundled engine.
- This native version is Android only. An iPhone version would need a separate implementation.
- Only download videos you own or have permission to save.

## Build independently

Open in Android Studio, install Android SDK 35, and use Java 17 with Gradle 8.13. Python 3 is required to fetch and checksum-verify the bundled engine during the build. Run `gradle testDebugUnitTest assembleDebug`. The included GitHub Actions workflow performs the same build and uploads the APK after pushes to main. A Gradle wrapper is included when generated by the verified local build.

The app uses youtubedl-android 0.18.1 from Maven Central:
https://github.com/yausername/youtubedl-android

The Android library bundles native executables. APK size is larger than a normal web app. For public distribution, review all dependency notices and FFmpeg licensing, use your own release signing key, and add update distribution. Debug signing keys can change between CI runners, so subsequent builds may require uninstalling an older debug build before installation. Uninstalling removes preferences and the recent list, while published files remain in Downloads.
